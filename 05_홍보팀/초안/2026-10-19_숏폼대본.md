상태: **초안. 촬영·게시 금지 — 결재 후 진행.** 유튜브 쇼츠는 출시 후 채널이므로 릴스용으로 먼저 쓰고, 출시 후 같은 영상을 쇼츠로 재사용.
공통: 현대차 로고·차량 공식 영상·줌 로고/고유 UI 사용 금지. 화면은 자체 프로토타입(`app/app.html`) 캡처와 자체 그래픽만. 프로토타입 화면에는 "개발 중 화면" 상시 표기. 마지막 2초에 고지 자막.

## 대본 1 — "PT 면접, 회의실에 다른 팀이 있다면?" (제품 콘셉트)

| 시간 | 화면 | 자막 / 내레이션 |
|---|---|---|
| 0~3초 | 화상 면접 화면(일반 화상회의 레이아웃, 브랜드 없음). 면접관 타일은 실루엣 | "PT 면접 시작하겠습니다." |
| 3~7초 | 발제 카드 등장: "10/14 인도 푸네 신공장 준공 · 2032년까지 155억 달러 투자" | "오늘 발제는 최신 뉴스입니다." |
| 7~11초 | 직무 선택 화면 (원가·구매·생산관리·품질·해외영업·재무) → "구매" 선택 | "당신은 구매팀입니다." |
| 11~18초 | 화면이 회의실 전체 보기로 전환. 아바타가 다른 팀 자리로 이동하며 말풍선 표시: 생산관리 "증설 속도를 높여야 합니다" / 재무 "회수 기간은요?" | "다른 팀은 이미 주장을 내놨습니다." |
| 18~24초 | 내 차례 타이머 표시, 발표 화면 | "현지 부품 조달, 어디까지 늘릴 건가요? 당신 팀의 의견을 발표하세요." |
| 24~28초 | 질의응답 → 자가점검 리포트 화면 스치듯 | "반박, 질의응답, 그리고 스스로 점검하는 리포트까지." |
| 28~30초 | 서비스명 + "출시 전 대기자 모집 중 · 프로필 링크" + 고지 | 고지: 현대자동차와 무관한 독립 서비스 · 개발 중 화면 |
