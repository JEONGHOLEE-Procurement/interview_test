# 면접 준비 시뮬레이터

서류 합격 후 면접을 앞둔 대기업 지망 취준생을 위한 면접 준비 플랫폼.

## 프로토타입: 현대자동차 PT 면접 회의실
- `app/index.html`: 랜딩 페이지
- `app/app.html`: PT 면접 회의실. 뉴스 발제 → 직무별 화두 → 부서별 발표 → 내 1장 PPT 발표 → 반박 대응 → 질의응답 → 자가 점검
  - 줌 면접 화면과 회의실 전체 보기(메타버스, WASD·클릭 이동)를 오갈 수 있음
- `app/data/scenario-hyundai-india.js`: 시나리오 데이터 (백엔드 `GET /api/scenarios/:id` 응답 형식)
- 백엔드 데이터 명세: `03_개발팀/설계/PT면접-백엔드-데이터명세.md`

브라우저로 `app/index.html`을 열면 바로 실행됩니다. 서버나 빌드는 필요 없습니다.
