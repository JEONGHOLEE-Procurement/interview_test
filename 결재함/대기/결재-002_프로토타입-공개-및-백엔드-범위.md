# 결재-002: PT 면접 프로토타입 공개 범위와 백엔드 구축 시점

## 결정할 것
현대차 PT 면접 프로토타입을 누구에게 공개할지, 그리고 백엔드(세션 저장·AI 평가)를 언제 만들지 정한다.

## 배경
- 오너 지시로 프로토타입을 만들었다: `app/index.html`(랜딩), `app/app.html`(회의실). 로컬 Chrome에서 입장부터 결과까지 전 과정이 오류 없이 동작하는 것을 자동 테스트로 확인했다.
- 지금은 서버가 없다. 입력 내용은 브라우저 밖으로 나가지 않고, 점수는 키워드·구조 기반 임시 채점이다.
- 백엔드에서 받을 데이터와 API: `03_개발팀/설계/PT면접-백엔드-데이터명세.md`
- 홍보팀 결재-003(채널 계정 개설)이 승인되면 게시물이 연결할 링크가 필요하다.

## 선택지
| | A안. 비공개 테스트 | B안. 정적 공개 + 대기자 폼 (권고) | C안. 공개 + 백엔드 MVP |
|---|---|---|---|
| 내용 | 링크 없이 지인·인터뷰 대상 5~10명에게 화면 공유로만 시연 | 무료 정적 호스팅(GitHub Pages 등)에 공개. 서버 없음. 랜딩에 대기자 신청 폼 연결 | B + 세션 저장, AI 평가 리포트(Claude API), 관리자 발제 등록 |
| 비용 | 0원 | 0원 (도메인 구입 시 연 2~3만 원 수준, 추정) | 서버 + AI 사용량 비례 비용 (금액 미산정, 착수 전 재결재) |
| 기간 | 즉시 | 1일 | 2~3주 |
| 장점 | 위험 없음 | 홍보 링크 목적지 확보, 실제 반응 측정 시작 | 진짜 피드백(AI 평가) 제공 |
| 리스크 | 반응 데이터가 거의 없음 | 임시 채점이 "평가"로 오해될 수 있음 → 화면에 임시 채점 명시 | 수요 검증 전 비용 지출, 개인정보 저장 시작 |

## CEO 권고
**B안.** 면접 시즌이 진행 중이라 지금 링크를 열어 반응부터 보는 것이 맞다. 서버가 없어 개인정보 위험도 없다. 백엔드(C안)는 B안으로 2주 동안 체험 수·완주율·대기자 수를 본 뒤 비용을 산정해 다시 결재를 올린다.
